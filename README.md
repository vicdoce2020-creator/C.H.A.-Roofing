# C.H.A. Roofing Landing Page

A responsive static landing page built with HTML, CSS, and jQuery.

## Files
- `index.html` — page structure and content
- `style.css` — responsive styling, layout, and animations
- `script.js` — jQuery navigation, scroll reveal, and quote form behavior

## Run locally
Open `index.html` in a browser. An internet connection is used for Google Fonts, jQuery CDN, and Unsplash photos.

## Important before publishing
- Confirm business details, phone number, service area, and claims with C.H.A. Roofing.
- Replace image URLs with approved project photography if available.
- The quote form is a front-end demo. It opens the visitor's email client and does not save or send submissions to a server. For production, connect a secure form backend or CRM and use the business's approved email address.
- The Google reviews area links to the Google Business Profile; it does not fabricate customer testimonials.
- This is a concept landing page, not an official website or representation authorized by the business.
